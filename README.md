# Roubiniol

A compact personal directory for Achille's games, software, and experiments. Sidearm is its single featured project, in development. The intended home is [achille.roubiniol.eu](https://achille.roubiniol.eu/).

GitHub provides the current contact route. The domain email appears only after mailbox verification. The Roubiniol mark is provisional; the separate cartoon mascot proposal awaits human review. Audience measurement remains disabled pending its server verification.

This source is independent of Sidearm's website. AGPL-3.0-only covers the site; bundled fonts include their SIL Open Font License notices. [CODEMAP.md](CODEMAP.md) describes local builds and acceptance.
